# عروض الجلسات | Session slide decks

> هذا الملف توثيق لصيغة المصدر. لا يُبنى كعرض (المولّد يتجاهل `README.md`).

هنا تُكتب مصادر العروض التقديمية (PPTX) للجلسات. كل ملف = عرض واحد، ويُبنى بالأمر:

```bash
python3 tools/build_slides.py            # بناء كل العروض إلى slides/*.pptx
python3 tools/build_slides.py s3         # عرض واحد فقط (مطابقة جزئية للاسم)
python3 tools/check_slides.py            # فاحص جودة بنيوي لكل العروض
python3 tools/check_slides.py s6         # فحص عرض واحد
```

## صيغة المصدر | Source DSL

### 1) ترويسة العرض (JSON) — أول سطر إلزامي

```text
---
{
  "deck": "الجلسة 03 — الفرع وطلب السحب",
  "kicker": "ورشة GIT وGITHUB — البرنامج التدريبي العملي",
  "footer": "ورشة Git وGitHub · الجلسة 03 — الفرع وطلب السحب"
}
---
```

- `deck` يظهر أعلى كل شريحة مع رقمها (`… · 5/14`).
- `kicker` يُستعمل في شريحة العنوان، و`footer` أسفل شريحة العنوان.
- **لا فواصل زائدة** في JSON (بدون فاصلة قبل `}` أو `]`).

### 2) الشرائح

```text
:::slide{layout="title" title="عنوان الجلسة" subtitle="Session 03 · Branch & PR" kicker="…"}
:::

:::slide{title="عنوان الشريحة"}
… محتوى الشريحة …
:::
```

- الشريحة الأولى تُرسم كشريحة عنوان تلقائياً (خلفية كحلية + شريط برتقالي).
- `layout="title"` لإجبار شريحة داخلية على قالب العنوان.

### 3) كتل المحتوى (داخل الشريحة)

| الصيغة | الأثر |
|---|---|
| `- سطر` | قائمة نقطية (RTL) |
| سطر عادي | فقرة نصية |
| `:::code` … `:::` | صندوق كود داكن، بلا RTL، تلوين تلقائي |
| `:::code{size="11"}` | نفس الصندوق بحجم خط أصغر (للأكواد الطويلة) |
| `:::callout{type="info"}` | صندوق ملاحظة ملوّن حسب النوع |
| `:::img{name="ci-flow"}` | صورة من `assets/img/png/<name>.png` |
| `:::cols` … `---` … `:::` | عمودان متجاوران (تُفصل بمفرد `---`) |
| `:::table` مع أسطر `\|` | جدول بترويسة كحلية وصفوف متبادلة |

أنواع `callout`: `info` · `tip` · `warn` · `err` · `ok` · `rule`.
وتلوين الكود: الأسطر التي تبدأ بـ `$` → سماوي، و`#` / `//` → رمادي،
و`fatal:` / `error:` / `CONFLICT` / `✘` → أحمر.

### 4) التنسيق داخل السطر

- `**عريض**` → نص عريض فعلي داخل الشريحة.
- `` `كود` `` → مقطع بخط Consolas.

### 5) قواعد يجب مراعاتها

1. **أغلق كل كتلة** بـ `:::` — الكتلة غير المغلقة تبتلع بقية الشريحة.
2. لا تستخدم رموزاً تعبيرية (emoji): تُظهر مربعات فارغة. المولّد يستبدل المشهور منها
   (`✔ ✘ ● ▣ ➜ ☐ ★`)، والمجموعة الآمنة في كل البيئات هي:
   `✔ ✘ ✓ ✗ ★ ◆ ● ■ ▲ ☐ → ⇒ ⚠ ← • ─ │ ├ └`.
3. حافظ على مساحة أسفل الشريحة: المولّد يطبع تحذيراً إذا تجاوز المحتوى ارتفاع الشريحة
   (`⚠ تحذير تخطيط: الشريحة …`) — قلّل الأسطر أو اجعل `size` أصغر، أو اقسم الشريحة.
4. الشرائح للمحاضرة لا للقراءة: 4–6 نقاط كحد أقصى، والمصدر المطوَّل يبقى في ورقة العمل.

## سير العمل المقترح | Suggested workflow

1. عدّل/أضف ملف `s‹n›-…md`.
2. `python3 tools/build_slides.py s‹n›` ثم `python3 tools/check_slides.py s‹n›` (يجب أن يخرج بلا ملاحظات).
3. افتح `slides/s‹n›-….pptx` في PowerPoint واعرض الشريحة الأولى على الشاشة للتأكد من الخط
   (إن لم يكن `Cairo` مثبتاً على جهازك، اختر بديلاً عربياً واضحاً مثل `Tahoma` أو
   ثبّت الخط من Google Fonts — بقية الملف لا يتأثر).
