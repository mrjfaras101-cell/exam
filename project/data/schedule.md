# جدول جلسات الورشة | Workshop schedule

| # | الجلسة / Session | المدة / Time | المخرجات / Deliverables |
|---|---|---|---|
| 1 | التهيئة والتعريف بـ Git وGitHub | 60 دقيقة | حساب GitHub + Git مثبّت + مفتاح SSH أو PAT |
| 2 | إنشاء المستودع والالتزام الأول | 60 دقيقة | مستودع `class-team-hub` + أول `commit` |
| 3 | السحب والتعديل الأول | 60 دقيقة | بطاقة الطالب مرفوعة على فرعه الخاص |
| 4 | طلب السحب والمراجعة | 60 دقيقة | Pull Request مفتوح + تعليق مراجعة |
| 5 | الدمج ومختبر التعارضات | 90 دقيقة | `main` محدَّث + تمرين حل تعارض ناجح |
| 6 | النشر والمراجعة النهائية | 45 دقيقة | GitHub Pages يعمل + تقرير الفريق |

## قواعد الجلسات
1. لا عمل مباشر على `main` — كل تعديل عبر فرع + طلب سحب.
2. رسالة الالتزام بصيغة `type(scope): وصف قصير`.
3. كل طالب يزامن فرعه من `main` **قبل** أن يبدأ أي تعديل جديد.
4. من ينتهي أولاً يراجع طلب سحب زميله (مراجعة إلزامية قبل الدمج).
