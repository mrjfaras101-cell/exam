كيف تضيف بطاقتك؟ / How to add your card

  1. أنشئ فرعاً: git switch -c feature/<username>-card
  2. انسخ data/members/00-template.json إلى data/members/<username>.json
  3. املأ الحقول الخمسة الإلزامية، ثم git add و git commit و git push
  4. افتح طلب سحب (Pull Request) واطلب مراجعة زميل
