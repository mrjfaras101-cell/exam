## 1. التشغيل السريع

```bash
# المتطلبات: Flutter 3.27+ (Dart 3.6+)
flutter pub get
flutter analyze
flutter test
flutter run                # على جهاز/محاكي متصل
```

أول مرة فقط (إذا لم تكن مجلدات المنصات موجودة):


## 3. كيف تُستخدم عمليًا (مسار المعلم)

1. **اختبار جديد**: الاسم، المادة، الصف، عدد الأسئلة (1–20)، نوع الأسئلة (دائرة/مزيج/نعم-لا)، عدد الخيارات (2–5).
   يُخصَّص للاختبار **رقم (0–31)** يُطبع في «رمز الورقة» ليُتعرَّف عليه آليًا.
2. **الورقة والطباعة**: معاينة مطابقة للمليمتر → طباعة أو PDF أو مشاركة. **اطبع على مقياس 100%** (لا Fit to page)، ورق أبيض.
3. **مفتاح الإجابة**: المس الإجابة الصحيحة لكل سؤال، أو اطبع «ورقة المفتاح» (تحمل بتّة المفتاح) وامسحها بالكاميرا.
4. **وزّع الأوراق** على الطلاب؛ يظلّل الطالب دائرة الإجابة ورقم جلوسه في شبكة الأرقام.
5. **التصحيح**: وجّه الكاميرا؛ التطبيق يقرأ ويحسب ويسجّل تلقائيًا ويثبّت كل ورقة، ويعرض بطاقة النتيجة فورًا.
   أوراق ممسوحة بكاميرا الجوال من قبل؟ استخدم أيقونة **المعرض** لتصحيح دفعة صور مرة واحدة.
6. **النتائج**: إحصاءات الصف، توزيع الدرجات، تحليل كل سؤال (صعوبة/تمييز/توزيع)، مؤشر «راجع المفتاح»، تصدير CSV.

## 4. المعايرة الميدانية (مهمّة)

إذا تكرّر وسم أوراق كثيرة كـ«تظليل خفيف» أو «فارغ»:

| المشكلة | الحل في شاشة الإعدادات |
|---|---|
| الطلاب يظلّلون بقلم رصاص/باهت | اخفض **عتبة «مظلّلة»** (0.45 → 0.38) |
| ورق فوتوكوبي داكن/رمادي | اخفض **نسبة الحبر مقابل الورق** (0.74 → 0.68) |
| تسرّب حبر من الورقة أو أثر ضغط القلم على الوجه الآخر | ارفع **نسبة الحبر مقابل الورق** (0.74 → 0.80) |
| فقاعات كثيرة «فارغة» رغم تظليلها | اخفض **عتبة «خفيف»** (0.18 → 0.14) |

القيم تُحفظ في قاعدة البيانات وتُستخدم فورًا في المسح التالي. الاختبار المرجعي: اطبع ورقة واحدة، ظلّلها
بعنف مرة وبخفّة مرة، وامسحها — يجب أن تُقرأ الأولى «ok» والثانية «light».

## 6. حدود النسخة الحالية (بصراحة)

- لا يوجد تراجع/إعادة (Undo) لتعديل الإجابات اليدوية.
- لا يوجد استيراد لقائمة أسماء الطلاب دفعة واحدة (يمكن إدخال الاسم لكل رقم جلوس).
- الصور لا تُحفظ افتراضيًا (خصوصية)؛ لا شاشة «مراجعة بالصورة» بعد — المراجعة تُعرض كقائمة أوراق/أسئلة.
- الدقة على أوراق مطبوعة حقيقية تحتاج اختبارًا ميدانيًا (المُختبَر حتى الآن أوراق اصطناعية بمحاكاة مخروطية وضوء وظلال واهتزاز).

## 7. الخط العربي والطباعة

- خط **Cairo** مُضمَّن في `assets/fonts/` (أوزان 400 و700) بموجب OFL — انظر `assets/fonts/OFL.txt`.
- PDF يُرسم بالكامل على صورة بدقة 300 نقطة/بوصة ثم تُغطّى الصفحة كاملة (بلا هوامش)، لتفادي مشاكل
  تشكيل العربية في مولّدات PDF. حجم الصفحة A4 (210×297 مم) — تأكّد من إعداد الطابعة على **100%**.
